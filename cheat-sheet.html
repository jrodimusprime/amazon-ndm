What Network Core is

  • Software + ops plane for regional AWS DC/core network fabrics
  • You (SDM): lead SysDEs — roadmaps, CR, deploy, monitor, hire/grow
  • SysDEs: build tools that build/operate/monitor/assure the network
  • NDEs: Clos/fabric design, routing, availability, compliance, change
  • Not: customer VPC SA day job; not CLI-only NOC manager

Fabric first principles

  • Underpin: EC2/EBS/S3/platforms need fabric BW + recovery
  • Region: AZ/DC fabrics + metro interconnect
  • Sustain (ops): repeatable scale, change safety, no heroics
  • Sustain (power): leaner fabric → more server watts

Reliability design

  • Independent diversity · N-k capacity · graceful degrade
  • Gray failure probes · control≠data plane
  • Drain → canary → rollback · no stacked domains
  • AZ isolation · safe automation · COE→mechanism

Top LPs

  • Dive Deep · Ownership · Deliver Results
  • Hire & Develop · Highest Standards
  • Customer Obsession · Earn Trust · Bias for Action

Ops triage

  1. Impact — who, how much, since when?
  2. Mitigate — restore customers first
  3. Scope — failure domain / blast radius
  4. Change correlate — deploys, peers, fiber
  5. Dive deep — telemetry, not guesses
  6. Durable fix — stop recurrence

Green ≠ healthy

  • Probe miss path/region/cohort
  • Admin-up without traffic/errors

Change & capacity

  • Peer review · canary · rollback · owner
  • No overlapping failure-domain changes
  • Forecast: peaks + growth + repair margin
  • Lead indicators → capacity before demand
  • Emergency change = fast + audited

Physics napkin

  • 1 TB @ 10 Mbps ≈ 9.3 days
  • Always convert to same units (Mb)

Fabric flash points

Software platforms

  • CI → staged rollout → health gates → rollback
  • Idempotent jobs; intended-state / drift detection
  • SLIs for ops APIs + change pipeline
  • Automate high-frequency toil with validation
  • RCA → mechanism so the bug class dies
  • Hands-on: unblock reviews/incidents; don’t solo-code the org

Manager moves

  • Hire SysDEs: systems + code + ops judgment
  • High performer: stretch + visibility
  • Low performer: expectations + plan + timeline
  • 24×7: fair rotation + page hygiene
  • Status: R/Y/G · risks · asks · impact
  • NDE asks vs debt: transparent tradeoffs
