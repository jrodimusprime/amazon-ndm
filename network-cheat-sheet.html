TCP/IP map

  • App ≈ L5–7 · Transport ≈ L4 · Internet ≈ L3 · Link ≈ L1–2
  • Troubleshoot by layer: L1 → L2/L3 → L4 → app

Planes & tables

  • Control plane: protocols build RIB (BGP/OSPF/IS-IS)
  • Forwarding / data plane: ASIC uses FIB + adjacency
  • RIB ≠ FIB — always validate actual forward path
  • CAM/TCAM: MAC, routes, ACLs — finite scale
  • ARP: next-hop IP → MAC for L2 delivery
  • CoPP: protect CPU from punt floods

L3 hop rewrite

  • Lookup NH · rewrite dest MAC · TTL−− · tx
  • TTL bounds loops

Fabric & region

  • Clos / spine-leaf: multipath east-west scale-out
  • ECMP: hash flows across equal-cost members
  • Underpin: EC2/EBS/S3 need BW + fast recovery
  • Region: AZ/DC fabrics + metro interconnect
  • AZ isolation: no shared fabric fate across AZs
  • eBGP underlay: policy + ECMP (RFC 7938 style)
  • IGP: OSPF/IS-IS for interior topology tradeoffs

Reliability

  • N-k capacity · independent diversity
  • Gray failure probes · graceful degrade
  • Drain → canary → rollback

Protocols & attachment

  • BGP: path attributes / policy · eBGP vs iBGP
  • BFD: fast detect vs false positives
  • LACP/LAG: bundle + hash; member failure
  • MLAG: dual-home across ToR pair
  • ToR vs EoR: cable, domain, upgrade model
  • Breakout / SerDes: port math & cabling
  • FEC: bit-error correction @ high rates
  • MTU / jumbo: mismatch = black hole
  • Underlay / overlay: VXLAN rides fabric IP

Triage order

  1. Impact — who / how much / since when
  2. Mitigate — restore customers
  3. Scope — failure domain
  4. Correlate — change / peer / fiber
  5. Evidence — errors, drops, probes, sessions
  6. Durable fix — stop the class of bug
